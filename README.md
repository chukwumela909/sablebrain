# Sablebrain

A simple one-page Next.js demo landing page using the Cadence brand system.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run lint
npm run build
```

## Brand notes

The page uses Cadence's midnight, ice, and steel palette, the rhythm-bar mark,
and plain-spoken AI operations messaging from the agency brand guidelines.
